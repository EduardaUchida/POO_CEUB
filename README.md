# Programação Orientada a Objetos — C#
Este repositório foi criado para reunir os estudos, exercícios e projetos desenvolvidos durante as aulas de Programação Orientada a Objetos (POO), utilizando a linguagem C#.

📚 Conteúdos estudados

Durante o desenvolvimento da disciplina, estamos aprendendo conceitos fundamentais de programação e orientação a objetos, incluindo:
Características de uma linguagem de programação

Paradigmas de programação, como:
Paradigma imperativo
Paradigma funcional
Paradigma lógico
Paradigma orientado a objetos
Métodos e sua utilização na organização do código
Classes e objetos
Encapsulamento
Abstração e seus pilares
Palavras-chave da linguagem C#
APIs (Application Programming Interface)
Estrutura e organização de aplicações em C#
Boas práticas de programação e organização de código

💻 Linguagem utilizada

A principal linguagem utilizada neste repositório é o C#, uma linguagem de programação moderna, orientada a objetos e desenvolvida pela Microsoft.
Os exemplos e exercícios presentes aqui têm como objetivo colocar em prática os conceitos apresentados em aula, desenvolvendo gradualmente a compreensão sobre programação e os princípios da orientação a objetos.

🎯 Objetivo

O objetivo deste repositório é acompanhar minha evolução no aprendizado de Programação Orientada a Objetos, registrando exercícios, exemplos e projetos desenvolvidos ao longo da disciplina.

Este repositório está em constante desenvolvimento conforme novos conteúdos são estudados e aplicados na prática.
